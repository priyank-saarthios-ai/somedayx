Search your X bookmarks from Claude, the ChatGPT desktop app, Codex and Cursor (MCP)

Short answer: install SomedayX (free, Mac), click its menu bar icon → AI Apps (MCP) → Let AI Apps Search My Saves, then choose Connect Claude Desktop, Connect ChatGPT Desktop & Codex, Connect Cursor or Copy Claude Code Command. Your AI app can then search everything you've bookmarked or liked on X, by meaning and inside screenshots. It's read-only and off until you turn it on. ChatGPT works in the desktop app for Mac and Codex, not in chatgpt.com in a browser.

What you can ask

  • "Find the posts I saved about pricing and summarise the advice."
  • "What did I bookmark about AI agents this month?"
  • "Pull every screenshot I saved about Postgres tuning and list the tips."
  • "Who do I save the most, and what do they post about?"

Set it up

  1. Install SomedayX and let it finish its first sync.
  2. Click the SomedayX icon in the menu bar → AI Apps (MCP) → Let AI Apps Search My Saves, and confirm.
  3. In the same menu:
    • Connect Claude Desktop or Connect Cursor: SomedayX adds itself to that app's MCP settings (keeping a backup). Quit and reopen the app.
    • Connect ChatGPT Desktop & Codex: SomedayX adds itself to ~/.codex/config.toml, which the ChatGPT desktop app, Codex CLI and Codex IDE extension share (keeping a backup). Reopen ChatGPT or start a new Codex session; it appears under Settings → MCP servers.
    • Copy Claude Code Command, then paste it in your terminal:
      claude mcp add --scope user somedayx -- ~/Applications/SomedayX.app/Contents/Resources/somedayx-mcp
    • Copy Setup for Other Apps: the JSON config for any app that supports local (stdio) MCP servers.

Apps that aren't installed show as "(not installed)". SomedayX checks without running them, so you won't see security warnings.

ChatGPT: SomedayX works in the ChatGPT desktop app for Mac and in Codex (CLI and IDE extension). It does not work in chatgpt.com in a browser or in the ChatGPT phone apps: those can only connect to MCP servers on the internet, and SomedayX keeps your saves on your Mac.

Privacy

  • Off by default. Until you turn it on, the server refuses every request. Turn it off in the same menu and it stops answering at once.
  • Read-only. It opens your library read-only and can't sync, post, like, or touch your X login.
  • Your AI app sees what it asks for. Cloud-based apps (Claude, ChatGPT, Codex, Cursor) send the posts they read to their servers to answer you. Your saves stay on your Mac unless you connect one.
  • Works without the app open. It shares SomedayX's on-device search model rather than loading a second copy, and the model frees its memory when idle.

FAQ

Is there an MCP server for X (Twitter) bookmarks?

Yes. SomedayX includes a free, open-source, read-only MCP server that lets Claude Desktop, Claude Code, the ChatGPT desktop app, Codex, Cursor and other MCP apps search your X bookmarks and likes by meaning, on your Mac.

Does it work with ChatGPT?

Yes, in the ChatGPT desktop app for Mac and in Codex (CLI and IDE extension). Not in chatgpt.com in a browser or the ChatGPT phone apps, which only connect to MCP servers on the internet; SomedayX keeps your saves on your Mac.

Does it need the X API or an API key?

No. SomedayX reads your saves into a local library on your Mac, and the MCP server searches that library. No X API, no API key, no account.

Does the SomedayX app need to be open?

No. Your AI app starts the server when it needs it. SomedayX keeps your library up to date when it syncs.

Can my AI app change or post anything?

No. Every tool is read-only, and the server opens the database read-only.
